# 🚀 Бесплатный хостинг для соцсети PRITONN

Для запуска PRITONN в интернете доступны 2 надежных и бесплатных варианта:

---

## ⚡ Вариант 1. Мгновенный бесплатный онлайн-хостинг (в 1 клик прямо с ПК)

Этот способ не требует регистрации, привязки карт или настройки серверов. Вы получаете рабочую публичную ссылку с HTTPS прямо сейчас:

1. Запустите сервер (если еще не запущен):
   ```bash
   node server/server.js
   ```
2. Запустите файл **`Запустить_Бесплатный_Онлайн_Хостинг.bat`** (или выполните команду `npx localtunnel --port 4000`).
3. В консоли появится публичная ссылка вида:
   ```
   your url is: https://bright-puma-42.loca.lt
   ```
4. Отправьте эту ссылку друзьям или откройте на телефоне!
   > При первом входе сайт `loca.lt` может попросить ввести ваш внешний IP — узнать его в 1 клик можно на [loca.lt/mytunnelpassword](https://loca.lt/mytunnelpassword) или [2ip.ru](https://2ip.ru).

---

## ☁️ Вариант 2. Бесплатный круглосуточный облачный хостинг 24/7 (Render.com)

**Render.com** предоставляет бесплатный тариф для Node.js приложений с полной поддержкой WebSockets (Socket.IO):

1. **Загрузите проект на GitHub**:
   * Создайте репозиторий на [github.com](https://github.com).
   * Загрузите папку с проектом `telegram-clone`.
2. **Зарегистрируйтесь на [Render.com](https://render.com)** (через GitHub в 1 клик).
3. **Создайте Web Service**:
   * Нажмите **New +** -> **Web Service**.
   * Выберите ваш репозиторий PRITONN.
   * Render автоматически подхватит конфигурацию из файла `render.yaml`, либо укажите:
     * **Runtime**: `Node`
     * **Build Command**: `cd client && npm install && npm run build && cd ../server && npm install`
     * **Start Command**: `node server/server.js`
     * **Plan**: `Free`
4. Нажмите **Deploy Web Service**.
5. Через 1-2 минуты у вас будет постоянный круглосуточный адрес вида:
   `https://pritonn.onrender.com`

---

## 📱 Как пользователи заходят с телефона (Android / iOS):
* Достаточно открыть полученную ссылку (`https://...`) в мобильном браузере (Chrome / Safari).
* Нажать **«Установить приложение PRITONN на главный экран»** — приложение автоматически установится как автономное мобильное приложение со своей иконкой!
